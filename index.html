📋 Términos y Condiciones de Uso

Antes de continuar, lee atentamente el alcance de esta plataforma:

  • Los valores de NDVI, NDWI, merma y costos son estimaciones estadísticas, no mediciones exactas de laboratorio.
  • Los precios provienen de datos históricos de ODEPA y pueden diferir del mercado actual.
  • Los datos climáticos son aproximaciones de Open-Meteo y los datos de suelo de SoilGrids ISRIC.
  • Esta plataforma no reemplaza la asesoría de un ingeniero agrónomo certificado ni informes del SAG.

Al continuar, aceptas que los datos son orientativos para planificación agrícola general.
✓ Funciona sin internet — los datos se guardan y sincronizan automáticamente.

📊 Fuentes y fiabilidad
Clima — Open-Meteo API
ET₀, temperatura, lluvia y humedad real por coordenadas GPS. Resolución ~1km.
✓ REAL — Tiempo real
Suelo — SoilGrids ISRIC
pH, MO, arcilla y arena por coordenadas. Base global calibrada, profundidad 0–30cm.
✓ REAL — Base global
Precios — Serie histórica ODEPA
$/kg oficial por cultivo y mes. Con red: mes actual. Sin red: rango histórico mín–máx.
✓ REAL — Fuente oficial ODEPA
Mano de obra — INE 2023
Jornal y jornadas/ha por cultivo y región. Encuesta Laboral Agrícola INE 2023.
✓ REAL — INE
NDVI / NDWI — Proxy meteorológico
Calculado via SM+ET₀. No es Sentinel-2. Resolución ~1km — predios cercanos muestran valores similares.
⚠ ESTIMADO — Proxy SM+ET₀
Rendimiento — Rangos INIA/ODEPA
Rango nacional por cultivo escalado por NDVI actual vs óptimo. No es medición del predio.
⚠ ESTIMADO — INIA/ODEPA
Precisión ±20–30%. Orientativo para planificación. Complementar con agrónomo certificado.
